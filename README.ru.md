SimpleRichText добавляет **Simple Rich Text Block** — наследник `URichTextBlock` с редактором отдельно форматируемых сегментов. Изменяйте текст и оформление каждого сегмента в панели Details: плагин создаст разметку и обновит стандартное свойство Text. Сегментами также можно управлять из Blueprint и C++.

## Возможности

- Цвет, шрифт, начертание и размер для каждого сегмента.
- Ввод текста отдельными сегментами или в одном поле с разделителем.
- Редактирование в панели Details: выбор цвета, меню форматирования, вставка и удаление строк.
- Стандартные возможности Rich Text Block, включая наборы стилей, декораторы и перенос текста.
- Создание и изменение текста во время выполнения через Blueprint и C++.
- Необязательная повторная генерация Text из сегментов при загрузке или пересоздании виджета.

## Требования

- Разработка и сборка выполнялись с **Unreal Engine 5.7**. Другие версии UE 5 не проверялись и могут потребовать изменения API.
- Среда сборки C++, настроенная для вашей версии Unreal Engine.

## Установка

1. Скопируйте или клонируйте репозиторий в папку проекта `Plugins/SimpleRichText`. Файл `SimpleRichText.uplugin` должен находиться непосредственно в этой папке.
2. Пересоздайте файлы проекта и соберите проект в IDE или через Unreal Engine.
3. Откройте проект, при необходимости включите **SimpleRichText** в **Edit → Plugins** и перезапустите редактор по запросу.

```text
YourProject/
└── Plugins/
    └── SimpleRichText/
        ├── SimpleRichText.uplugin
        └── Source/
```

Для использования из другого модуля C++ добавьте `SimpleRichText` в зависимости его файла `.Build.cs` и подключите `SimpleRichTextBlock.h`.

## Быстрый старт

1. Откройте Widget Blueprint и добавьте **Simple Rich Text Block** из категории палитры **Simple**.
2. Выберите виджет и добавьте элемент в **Text Segments** в разделе **Content** панели Details.
3. Введите текст и выберите цвет. В меню форматирования задайте шрифт, начертание или размер.
4. Кнопка **+** вставляет сегмент после текущей строки, **−** удаляет строку. Вставленная строка копирует её форматирование.
5. Сгенерированная разметка появится в стандартном свойстве **Text**, а предварительный просмотр обновится.

## Редактирование текста

### Per Segment Fields

Режим по умолчанию. В каждой строке есть многострочное поле текста и настройки форматирования. При изменении сегментов разметка записывается в **Text**. При добавлении пустого сегмента в редакторе существующий текст не перезаписывается, если сгенерированная разметка пуста.

### Single Field + Separator

Выберите **Single Field + Separator** в **Input Mode** и введите весь текст в **Combined Text**. Разделитель по умолчанию — `|`:

```text
Hello |beautiful |world|!
```

Строка делится на четыре части вместе с пробелами. Часть *N* получает формат сегмента *N*. В строках сегментов отображаются предпросмотр и настройки оформления. Дополнительные части копируют последний существующий формат; при уменьшении числа частей лишние сегменты и их форматы удаляются. Форматы сопоставляются по позиции, поэтому вставка разделителя в середине сдвигает форматирование следующих частей.

При переходе в этот режим существующие сегменты объединяются, если Combined Text пуст. Выберите разделитель, который не встречается в тексте: каждое его вхождение считается границей. Пустой разделитель оставляет всю строку одним сегментом.

### Свойства Details

| Свойство | Назначение |
| --- | --- |
| **Text** | Стандартное текстовое поле Rich Text Block; его можно редактировать вручную. Изменения сегментов заменяют его сгенерированной разметкой. |
| **Text Segments** | Упорядоченный список частей текста и их оформления. |
| **Always Rebuild From Segments** | По умолчанию выключено. Если включено, Text пересоздаётся при загрузке, синхронизации и пересоздании виджета, перезаписывая ручные изменения. |
| **Input Mode** | Выбор отдельных полей или одного общего поля. |
| **Combined Text** | Текст, разделяемый на части в режиме одного поля. |
| **Segment Separator** | Строка-разделитель; по умолчанию `|`. |

Каждый `FSimpleRichTextSegment` содержит `Text`, `Color` (по умолчанию белый), необязательный `Font` (`UFont` или `UFontFace`), необязательное имя `Typeface` и `Size` (`0` использует размер виджета по умолчанию). Незаданные шрифт и начертание берутся из базового стиля.

## Сгенерированная разметка

Каждый непустой сегмент преобразуется в элемент `<seg>`. Например:

```xml
<seg c="FF0000FF" f="/Game/Fonts/Roboto.Roboto" tf="Bold" s="32">Hello</>
```

| Атрибут | Значение |
| --- | --- |
| `c` | Цвет в формате sRGB `RRGGBBAA`; присутствует всегда. |
| `f` | Soft object path ресурса шрифта; отсутствует, если шрифт не задан. |
| `tf` | Имя начертания; отсутствует, если не задано. |
| `s` | Размер шрифта; отсутствует при значении ноль или меньше. |

Декоратор регистрируется автоматически. Он берёт базовый стиль текста виджета и применяет атрибуты сегмента. Перед генерацией разметки обратная косая черта, `<` и `>` в тексте сегмента экранируются. В стандартное поле Text можно добавлять собственные теги, однако следующее изменение сегментов заменит его сгенерированной разметкой. Ресурсы шрифтов загружаются по soft-путям при создании текстового элемента; убедитесь, что они доступны в собранной версии проекта.

## API Blueprint и C++

Операции с сегментами доступны в категории Blueprint **SimpleRichText**. Индексы начинаются с нуля; методы изменения и удаления игнорируют неверный индекс, а `GetSegmentText` возвращает пустой текст.

| Функция | Назначение |
| --- | --- |
| `SetSegments` | Заменить массив сегментов и обновить виджет. |
| `SetCombinedText` | Разделить общий текст текущим разделителем, сохранив форматы по позициям. |
| `SetCombinedTextWithFormats` | Разделить текст и применить форматы по порядку; поля текста в форматах игнорируются. |
| `SetFormats` | Применить форматы по позициям, сохранив текст; для оставшихся сегментов повторяется последний формат. Пустой массив ничего не меняет. |
| `SetSegmentFormat` | Заменить оформление одного сегмента, сохранив его текст. |
| `SetSegmentText`, `SetSegmentColor`, `SetSegmentSize` | Изменить один сегмент. Размер ограничивается значением не меньше нуля. |
| `SetAllSegmentsColor` | Изменить цвет всех сегментов. |
| `AddSegment`, `InsertSegment`, `RemoveSegment`, `ClearSegments` | Добавить, вставить, удалить или очистить сегменты. `AddSegment` возвращает индекс нового сегмента. |
| `GetSegmentCount`, `GetSegmentText`, `GetPlainText`, `BuildMarkup` | Получить сведения о сегментах, объединённый обычный текст или разметку. |

`AddSegment` и `InsertSegment` используют переданные текст и цвет. Если шрифт не задан, наследуется шрифт соседнего сегмента и, если начертание не задано, его начертание; размер ноль или меньше также наследуется. При вставке с индексом ноль используется первый существующий сегмент. `SetSegments` применяет переданные значения напрямую.

Пример для корректного указателя `USimpleRichTextBlock* RichText`:

```cpp
#include "SimpleRichTextBlock.h"

FSimpleRichTextSegment Greeting;
Greeting.Text = FText::FromString(TEXT("Hello, "));
Greeting.Color = FLinearColor::White;

FSimpleRichTextSegment Name;
Name.Text = FText::FromString(TEXT("world!"));
Name.Color = FLinearColor(1.0f, 0.3f, 0.4f);
Name.Size = 28;

RichText->SetSegments({Greeting, Name});
```

Изменение сегментов обновляет стандартное поле Text. Поэтому `ClearSegments()` очищает сгенерированный текст; сохраняйте вручную написанную разметку отдельно, если она понадобится снова.
